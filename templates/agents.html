How this works

Mark a company with "managed_by": "agent" in config.py - this server then stops polling it. Run agent.py at that site; it performs the Gateway/Internet/DNS/HTTPS checks locally and POSTs them to /api/ingest using the token below. Only a SHA-256 hash of each token is stored.
